# ヘキサフレキサゴン工房

折って、めくると絵が変わる六角形「ヘキサフレキサゴン」の型紙を作る単体HTMLアプリです。

- **トリヘキサフレキサゴン**（顔3つ・正三角形10枚の帯）
- **ヘキサヘキサフレキサゴン**（顔6つ・正三角形19枚の帯）

顔ごとに内蔵の絵柄（オリジナル幾何学模様6種×色合い6種）を選ぶか、自分の写真・イラストを読み込めます（端末内処理のみ、外部送信なし）。選んだ絵は、折り上がったときに六角形の1枚絵としてそろうよう、6つの三角形セクターに分割して帯の型紙へ自動配置します。めくりシミュレーター（顔の対応表つき）と作り方・めくり方の説明書、ガードナーとフレキサゴン委員会（1939年）のコラムを内蔵しています。

## 型紙の方式

- A4判・横向き、300dpi画像（3508×2480px）で書き出し。5cm較正線つき。
- 帯は「二つ折り方式」：表の絵の段と裏の絵の段を1枚の帯として印刷し、中心線で折って貼り合わせると表裏の位置が正確に合います。
- 数字は折るための目印で、トリはMorgan方式、ヘキサはガードナー方式の古典的な番号配置です。折り目の強調表示（赤①②③）、のりしろの明示つき。

## 面対応の検証について

帯の各三角形が「どの顔の・どのセクターに・どの回転で」現れるかの対応表は、三角格子上の折りシミュレーション（`foldsim.js`／`construct.js`）で帯の折り畳みを全探索し、ラベルの整合性（ヘキサは「裏の同数字同士が向かい合う」等）で一意に定まる状態だけを採用して作りました（`mapping.json`／`flexdata.json`）。

さらに、アプリ本体の型紙生成→組み立て直しの往復をピクセル単位で照合するテスト（`verify-flex.js`）で、全9顔×6セクターすべてが元の絵と一致（平均差分1.1以下＝再サンプリング誤差の範囲）することを確認済みです。

## ファイル

- `index.html` ― アプリ本体（自己完結・CDN不使用）。`template.html`＋`app-body.js`＋`flexdata.json` から `build-app.js` で生成
- `icon.png` / `icon-180.png` ― ホーム画面アイコン
- `flexdata.json` ― 面対応表（検証済みデータ）
- `mapping.json` / `foldsim.js` / `construct.js` ほか ― 対応表の導出・検証用スクリプト群
- `verify-flex.js` / `verify-ui.js` ― 検証スクリプト

## 残る実機確認（お願い）

- 型紙を実際に印刷して5cm線が実寸どおりか
- 実際に折って、顔の絵がそろうか／めくれるか（特にヘキサの隠れた顔4・5・6）
- iPhoneでの写真読み込みと操作感
